# ice-cake-cafe
A responsive web application for 'Ice Cake Cafe' that allows users to explore bakery products and customize their own cakes.
## Features
**User-Friendly Interface:** Clean and attractive design for a great user experience.
**Customization:** Features for users to select and personalize their cake orders.
**Fully Responsive:** Optimized for all devices including Mobiles, Tablets and Desktops.

## Technologies Used
**HTML5** - For the website structure.
**CSS** - For styling and responsive layout.
